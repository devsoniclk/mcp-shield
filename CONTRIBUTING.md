# Contributing to mcp-shield

We welcome community contributions, security audits, and new proxy filters!

## Development & Submissions
1. Fork the repository and create your feature branch.
2. Ensure proxy tests pass locally.
3. Submit a pull request with clear description of the threat model addressed.

## Co-Authorship
We encourage collaborative research and pair engineering. Tag co-authors using GitHub's `Co-authored-by:` git trailers.
